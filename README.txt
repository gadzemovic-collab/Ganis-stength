GANIS STRENGTH — INSTALL ON IPHONE

1. Unzip this file.
2. In Safari, go to https://app.netlify.com/drop
3. Upload the unzipped folder that contains index.html.
4. Netlify will give you a web address.
5. Open that web address in Safari.
6. Tap Share -> Add to Home Screen.
7. Turn on Open as Web App if shown, then tap Add.

The app's workout data stays in local storage on that iPhone/browser.
