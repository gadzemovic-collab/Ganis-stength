# RepHarbor roadmap

## Native iPhone app

- User-requested requirement, October 3, 2026: display the active rest timer on the iPhone lock screen using a Live Activity. Include Dynamic Island support on compatible devices.
- Keep the countdown synchronized with the workout's rest timer when the app is backgrounded or the phone is locked. Finish or dismiss the activity when rest completes or the timer is stopped.
- This is planned for a native iOS component; the current web app does not implement a lock-screen countdown.
